## 1. 게임 목표와 설계 철학

### 1.1 3대 설계 원칙
1. **속도가 곧 그래픽이다** — 화면 흔들림, 모션 블러, FOV 확장, 속도선으로 200km/h 체감.
2. **노면이 곧 플레이다** — 아스팔트/얼음/기름/비포장은 마찰·조향·제동 수치가 실제로 달라진다. 운전 실력이 아니라 **타이어와 노면 읽기**가 게임이다.
3. **파괴는 자원 소모다** — 사고는 감점이 아니라 "수리비"다. 그래서 상점이 의미 있고, 레이싱 승리가 보상된다.

### 1.2 하지 않는 것 (Non-Goals)
- ❌ 오픈월드 자유이동(도시 전체 샌드박스) — 트랙은 **코스로 제한**
- ❌ 온라인 멀티플레이 — 1차에서는 AI 경쟁만
- ❌ 실제 면허/법규 시뮬레이터 — "시뮬레이션"은 **차량 상태·물리 리얼리즘**을 뜻함
- ❌ 총기/경찰 추격 — GTA는 **감성(네온·도시·불법레이스)**만 가져온다 (순찰차는 M7 선택 장애물로만 고려)

## 4. 트랙/코스 설계

### 4.1 코스 생성 방식 — 프로시저럴 트랙 빌더 DSL (기술과 직결)
도로는 **세그먼트(segment)의 연속**으로 정의합니다. 단일 HTML 파일의 코드 비대화를 막기 위해 세그먼트 배열을 하드코딩하지 않고, **빌더 함수(DSL)**로 코스를 10~20줄 내에 선언적으로 생성합니다.

```js
// 세그먼트 1개 구조 (길이 = CONFIG.road.segLen = 200)
seg = {
  index: 0,
  curve: -2.5,          // -5(좌) ~ +5(우), 0=직선
  y: 0.0,               // 높이 (점프대/언듈레이션)
  surface: 'wet' | 'ice' | 'oil' | 'gravel' | 'asphalt' | 'concrete',
  width: 1.0,           // 도로 폭 배율 (좁은 길 = 난이도)
  props: [ {kind:'streetlight', side:-1, off:1.2}, {kind:'barrier', side:1, off:1.1} ],
  hazard: {kind:'oilSpill', x:-0.3, w:0.25} | null,
  jump: {rampHeight: 1.2} | null,
}

// 트랙 빌더 DSL 예시 (Road 모듈)
Road.addStraight(len, surface);
Road.addCurve(len, curve, surface);
Road.addHill(len, height, surface);
Road.addGimmick(startSeg, len, type);
```

### 4.3 코스 테마 요소 (화려함의 핵심)
- **가로등**: 세그먼트마다 좌/우 교대 배치. 빛은 도로 위에 **타원광(elliptical glow)**으로 실제 밝기 기여. 점멸/플리커는 GIF 프레임이 아닌 **렌더 루프의 `Math.sin(time)` + 난수 알파 변조**로 구현
- **네온 사인**: 한글/영문 간판, 광고판, 광고판 플리커(0.5초 주기)
- **빌딩 실루엣**: 패럴랙스(Parallax) 배경 3~6레이어(원경/중경/근경)
- **날씨**: 비(빗줄기 파티클 + 노면 반사), 안개(원경 시야 감소), 맑음
- **도로 외곽**: 가드레일, 콘, 신호등, 표지판, 간선 표지, 증기 맨홀

## 5. 노면(Surface) 시스템 — 이 게임의 핵심

모든 노면은 **4개 수치**로 정의됩니다. 이 표가 곧 밸런스의 기준입니다.

| 노면 | 그립(grip) | 최대속도 배율 | 조향 응답 | 제동력 | 추가 효과 |
|---|---|---|---|---|---|
| ⬛ 아스팔트 (건조) | 1.00 | 1.00 | 1.00 | 1.00 | 기준값 |
| 🌧️ 젖은 아스팔트 | 0.78 | 0.95 | 0.85 | 0.72 | 수막: 140km/h 이상이면 그립 추가 −15% |
| 🧊 얼음 | 0.32 | 0.85 | 0.35 | 0.28 | 관성 유지, 오버스티어 급발생. 스로틀로 드리프트 제어 |
| 🛢️ 기름 유출 | 0.18 | 0.85 | 0.20 | 0.15 | 진입 순간 조향 완전 무효 0.35초, 스핀(횡슬립) 위험 |
| 🏜️ 비포장(자갈) | 0.55 | 0.80 | 0.70 | 0.55 | 요철: 수직 바운스 + 스티어링 저터 + 시야 먼지 |
| 🟫 점프대(램프) | 0.90 | 1.05 | 1.00 | — | 공중 구간: 조향 30%만 유효, 착지 시 횡슬립/조향 과다 상태면 차체 파손 |
| ⬜ 콘크리트 | 1.05 | 1.02 | 1.05 | 1.05 | 상수 잘 보이는 특별 구간 |

### 5.1 gimmick 배치 규칙
- **기름 유출**: 화면에 **무지개빛 반사**(`oil.png` 또는 절차적 그라데이션)로 시각 안내. 직전 세그먼트에 경고 표지판.
- **얼음 구간**: 진입 전 300m 청색 LED 도로 매립등 + 김 서린 효과. 구간 진입 시 HUD에 `ICE` 경고 깜빡임.
- **비포장**: 진입 경계에서 `CLUNK` 사운드 + 카메라 셰이크. 바운스 진폭 = 속도 × 0.02
- **점프대**: 착지 지점에 초록 착륙 램프. **장거리 체공(Air Time ≥ 0.8초) 및 수평 안정 착지(`|lateralVel|` 낮음) 성공 시 에어 콤보 보너스(+300P)** (※ 2.5D 시점의 어색함을 피하기 위해 억지스러운 360° 차체 회전 대신 체공 시간 + 완벽한 착지 판정으로 대체)
- **주의**: gimmick은 최소 150m 간격, 같은 유형 연속 3회 금지 (좌절 방지)

## 7. 차량 물리 / 시뮬레이션

### 7.1 1차 물리 모델 (트랙 공간 2.5D 표준 모델 — v0.3 개정)
OutRun 계열 유사 3D 도로와 완벽히 맞물리도록 **트랙 상대 좌표계(`z`, `offsetX`, `y`)**를 사용합니다.

```
상태 변수:
  z          : 트랙 진행 거리 (0 ~ trackLength, 세그먼트 인덱스 = floor(z / segLen))
  offsetX    : 도로 중심 기준 정규화 횡방향 위치 (-1.0 = 좌측 끝, 0 = 중앙, +1.0 = 우측 끝, ±1.0 밖은 갓길)
  y, vy      : 수직 높이 및 수직 속도 (점프/언듈레이션용)
  v          : 전진 속도 (0 ~ maxSpeed)
  lateralVel : 횡방향 속도 (조향 + 원심력 + 슬립)
  driftAngle : 시각적 차체 꺾임 각도 (슬립율 표시 및 드리프트 판정용)

매 프레임(dt = 1/60) 업데이트 수식:
1) 가감속:
   v += (driveForce - drag·v² - rollResist - brakeForce·grip) / mass · dt
   (도로 외곽 |offsetX| > 1.0 주행 시 비포장 저항 추가 적용)

2) 조향 및 그립 지연:
   targetSteer = steerInput · steerSpeed · (1 - 0.35 · (v / maxSpeed))
   steerVel = lerp(steerVel, targetSteer, 1 - exp(-grip · 12 · dt))  ← 얼음/기름에서 조향 반응 지연

3) 커브 원심력 (Centrifugal Force):
   centrifugal = -seg.curve · (v / maxSpeed)² · CONFIG.physics.centrifugal
   lateralVel = steerVel + centrifugal / max(0.35, grip)

4) 드리프트 판정:
   slip = |steerVel - lateralVel| + (handbrake ? 0.6 : 0)
   if (slip > limitSlip && v > 80) → DRIFT 상태 (타이어 마모 ↑, 스키드마크/스모크, 드리프트 콤보 포인트)

5) 위치 적분 및 점프 탄도:
   offsetX += lateralVel · dt
   z = (z + v · dt) % trackLength
   if (inAir) { vy -= gravity · dt; y += vy · dt; }
   착지 순간(y <= seg.y): if (|lateralVel| > 1.2) → 불안정 착지 차체 손상 판정
```

## 8. 경쟁 AI

### 8.1 동작 원리
- **트랙 공간 주행**: 플레이어와 동일하게 `(z, offsetX, v)` 상태를 가지며, 세그먼트 중심선을 따라가되 차선 오프셋(`laneOffset`)으로 장애물 회피 및 추월/블로킹 수행
- **예측 감속**: 전방 8세그먼트를 look-ahead 해 곡률 최대값으로 목표 속도 계산
  `vTarget = maxSpeed * clamp(1 - |maxCurve| * 0.12 / grip, 0.45, 1.0) * skillMult`
- **스킬 레벨** (AI마다 배정, 코스별로 상승)

| AI 등급 | 목표속도 배율 | 반응 지연 | 실수율 | 특기 |
|---|---|---|---|---|
| D | 0.86 | 320ms | 14% | 초보, 코너 외곽 밀림 잦음 |
| C | 0.92 | 220ms | 9% | |
| B | 0.965 | 150ms | 5% | |
| A | 1.00 | 100ms | 2.5% | |
| S | 1.04 | 60ms | 1% | Rubberband 제외 |

### 8.2 Rubberband(접전 유지) 규칙 — **중요**
플레이어가 1위일 때 후방 AI 최고속 +6%, 플레이어가 최하위일 때 전방 AI −6%. 단, **S등급은 제외**. 역전 드라마를 만들되 조작감을 해치지 않는 선.

### 8.3 상호작용
- 추월 근접 시 슬립스트림(Drafting) 효과로 후방 차량 가속 +8%
- 플레이어 접촉 시 AI는 반대 차선으로 회피 시도 + 쌍방 차체 피해 누적
- AI끼리도 장애물 및 교통 차량 회피/충돌 처리

  - 주행 화면은 **후방 3/4 시점(OutRun 방식)**이므로, **플레이어 차량·AI 경쟁차·일반 교통차(승용차/트럭)는 모두 `Sprites.drawCar34()` 절차적 3/4 후방 뷰 렌더러로 그린다** (탑뷰 차량 이미지를 3D 도로 위에 그대로 띄우면 원근/시점이 어긋나는 문제 방지).

  - `assets/game/atlas/kenney_spritesheet_objects.png`의 콘, 배리어, 드럼통, 타이어 벽, 기름 웅덩이, 가로등 불빛은 2.5D 도로 위 빌보드 스프라이트로 적극 활용한다.

```
  Sprites     // Kenney 아틀라스 좌표 상수(SPRITES) + 스프라이트/절차적 통합 드로잉(drawProp, drawCar34)

  Road        // 프로시저럴 트랙 빌더(DSL) + 5개 코스 정의 + 세그먼트 조회
  Car         // 플레이어 차량 물리 업데이트 + 손상/타이어/연료/부스터 상태
  AI          // 경쟁 AI 및 일반 교통차(Traffic) 스폰·주행·Rubberband
  Physics     // 차량-장애물, 차량-차량 AABB/원형 충돌 및 노면 샘플링
  Render      // 유사 3D 투영, 패럴랙스 배경, 도로 폴리곤, 가로등 조명, 깊이 정렬(Painter's Algorithm)
  FX          // 파티클(스모크/스파크/비/속도선), 카메라 셰이크
  Race        // 랩/순위/체크포인트/타임어택 고스트/DNF 판정
  Economy     // 포인트 정산, 상점 구매, 업그레이드, 파산 방지 구난
  Save        // localStorage 직렬화/역직렬화
  UI          // 타이틀, 차고(HUB) DOM/Canvas UI, 레이스 HUD, 결과창, 크레딧
  Sound       // 외부 오디오 재생 + WebAudio 신스 폴백
  Loop        // requestAnimationFrame 고정 타임스텝(1/60) 메인 루프
}
```

### 12.3 유사 3D 도로 렌더러 (핵심 알고리즘)
```js
// 세그먼트를 카메라 기준 상대좌표로 변환하고 스크린 사다리꼴(Trapezoid)로 그림
project(p, camX, camY, camZ, camDepth, W, H, roadW) {
  const dz = Math.max(1, p.z - camZ);
  const scale = camDepth / dz;
  return {
    x: W / 2 + scale * (p.x - camX) * (W / 2),
    y: H / 2 - scale * (p.y - camY) * (H / 2),
    w: scale * roadW * (W / 2),
    scale
  };
}
// 1) baseSeg부터 drawDistance(200)개 세그먼트 순회하며 곡률 누적(x += dx, dx += seg.curve)
// 2) 뒤에서 앞으로(drawDistance → 1) Painter's Algorithm으로 도로 사다리꼴 + 연석(rumble) + 차선 렌더링
// 3) 세그먼트별 밝기 = 가로등 거리 함수(lampGlow) + 노면 색상 변조(얼음=청백색, 비포장=황토색, 젖음=어두운 반사)
// 4) 각 세그먼트에 속한 장애물(props)과 차량(AI/Traffic/Player)을 scale 비례 크기로 렌더링
```

## 13. 개발 로드맵 및 경량 모델(OpenCode) 작업 분할 가이드

단일 파일(`index.html`) 규모가 크므로, **OpenCode (`qwen3.8 flash next 3q` 등 경량/고속 모델)**에서 작업할 때는 한 번에 전체를 작성하지 말고 **아래 6개 Step 단위로 나눠 순차적으로 `edit_file`을 수행**합니다.

| Step (마일스톤) | 작업 범위 (`index.html` 섹션) | 검증 기준 (Definition of Done) | 권장 코드 분량 |
|---|---|---|---|
| **Step 1 (M0~M0.5)** | HTML/CSS 레이아웃 + `CONFIG` + `utils` + `Assets`/`Sprites` 로더(폴백 포함) + `Input` | 브라우저 실행 시 타이틀 화면 표시, 에셋 유무 관계없이 에러 0건 | ~450줄 |
| **Step 2 (M1)** | `Road` (트랙 빌더 DSL + 코스 5개) + `Render` (유사 3D 투영, 패럴랙스 배경, 가로등 조명) + `Car` 기본 주행 | 키보드로 가감속·조향·시점전환(`C`) 가능, 커브 원심력 및 60fps 확인 | ~550줄 |
| **Step 3 (M2)** | 노면 5종 물리(`wet`, `ice`, `oil`, `gravel`, `jump`) + 장애물/기믹 렌더링 및 `Physics` 충돌 판정 | 얼음/기름 미끄러짐 체감, 점프대 도약·착지, 콘/배리어/코인 충돌 동작 | ~400줄 |
| **Step 4 (M3)** | `AI` (경쟁차 5대 + 교통차 + Rubberband) + `Race` (랩/순위/체크포인트/카운트다운/결과 정산) | AI와 순위 경쟁 가능, 완주 시 순위 및 획득 포인트 계산 정확 | ~400줄 |
| **Step 5 (M4)** | `Car` 손상 4계통(엔진/타이어/연료/차체) + `Economy`(상점/업그레이드/파산방지) + `Save`(`localStorage`) | 차고에서 수리·업그레이드·차량구매 동작, 새로고침 후 저장 유지 | ~450줄 |
| **Step 6 (M5~M6)** | `Sound` (실물 오디오 + WebAudio 합성 폴백) + `FX` (파티클/네온/셰이크) + `UI` 마감(미니맵, 크레딧 화면) | 사운드 재생, 드리프트 스모크/부스터 연출, 크레딧에 CC-BY 저작자 표기 | ~450줄 |

> **💡 OpenCode (Qwen 3q 양자화 모델) 작업 시 주의사항:**
> 1. **앵커 주석 유지**: `index.html` 내부에 `// === [SECTION: ROAD] ===` 같은 명확한 주석 마커를 미리 배치해 두고, 각 Step에서는 해당 마커 위치만 교체(`edit`)하도록 지시하세요.
> 2. **수식/상수 하드코딩 제공**: 투영 공식(`project`)과 아틀라스 좌표(`SPRITES`)는 모델이 추론하게 두지 말고 본 기획서의 코드 블록을 그대로 복사해 넣도록 프롬프트를 주는 것이 안전합니다.
