## 1. 게임 목표와 설계 철학

### 1.1 3대 설계 원칙
1. **속도가 곧 그래픽이다** — 화면 흔들림, 모션 블러, FOV 확장, 속도선으로 200km/h 체감.
2. **노면이 곧 플레이다** — 아스팔트/얼음/기름/비포장은 마찰·조향·제동 수치가 실제로 달라진다. 운전 실력이 아니라 **타이어와 노면 읽기**가 게임이다.
3. **파괴는 자원 소모다** — 사고는 감점이 아니라 "수리비"다. 그래서 상점이 의미 있고, 레이싱 승리가 보상된다.

### 1.2 하지 않는 것 (Non-Goals)
- ❌ 오픈월드 자유이동(도시 전체 샌드박스) — 트랙은 **코스로 제한**
- ❌ 온라인 멀티플레이 — 1차에서는 AI 경쟁만
- ❌ 실제 면허/법규 시뮬레이터 — "시뮬레이션"은 **차량 상태·물리 리얼리즘**을 뜻함
- ❌ 총기/경찰 추격 — GTA는 **감성(네온·도시·불법레이스)**만 가져온다

## 4. 트랙/코스 설계

### 4.1 코스 생성 방식 (기술과 직결)
도로는 **세그먼트(segment)의 연속**으로 정의합니다. 각 세그먼트는 `curve`(곡률), `y`(경사), `roadType`(노면), `props`(가로등/빌딩/장애물)를 갖습니다.

```js
// 세그먼트 1개 (1/10단위 길이 단위)
seg = {
  curve: -2.5,          // -5(좌) ~ +5(우), 0=직선
  y: 0.0,               // 높이 (점프대/언듈레이션)
  surface: 'wet' | 'ice' | 'oil' | 'gravel' | 'asphalt',
  width: 1.0,           // 도로 폭 배율 (좁은 길 = 난이도)
  props: [ {kind:'streetlight', side:-1, off:0.6}, {kind:'barrier'}, ... ],
  hazard: {kind:'oilSpill', x:-0.3, r:0.25} | null,
  jump: {rampHeight: 1.2, landDist: 40} | null,
}
```

### 4.2 5개 코스 (1차 범위)
| # | 코스명 | 길이/랩 | 특징 | 노면 | 난이도 |
|---|---|---|---|---|---|
| 1 | **미드나잇 스트립** | 2랩 · 1.6km | 기본 입문. 가로등 긴 직선 + 완만한 S자 | 아스팔트 | ★ |
| 2 | **네온 다운타운** | 3랩 · 1.2km | 빌딩 빽빽, 네온 사인, 좁은 커브, 교통 차량 | 젖은 아스팔트 | ★★ |
| 3 | **하버 도크** | 3랩 · 1.4km | 컨테이너 장애물, 기름 유출, 급커브 | 아스팔트+기름 | ★★★ |
| 4 | **프로스트 브리지** | 2랩 · 2.0km | 다리 위 결빙 구간, 방호벽, 강한 돌풍 | 얼음 | ★★★★ |
| 5 | **스크랩 캐니언** | 3랩 · 1.5km | 비포장 공사장, 점프대, 낙하물, 요철 | 자갈/비포장 | ★★★★★ |

### 4.3 코스 테마 요소 (화려함의 핵심)
- **가로등**: 세그먼트마다 좌/우 교대 배치. 빛은 도로 위에 **타원광(elliptical glow)**으로 실제 밝기 기여
- **네온 사인**: 한글/영문 간판, 광고판, 광고판 플리커(0.5초 주기)
- **빌딩 실루엣**: 파라allax 배경 3레이어(원경/중경/근경)
- **날씨**: 비(빗줄기 파티클 + 노면 반사), 안개(원경 시야 감소), 맑음
- **도로 외곽**: 가드레일, 콘, 신호등, 표지판, 간선 표지, 화재 사다리, 증기 맨홀

## 5. 노면(Surface) 시스템 — 이 게임의 핵심

모든 노면은 **4개 수치**로 정의됩니다. 이 표가 곧 밸런스의 기준입니다.

| 노면 | 그립(grip) | 최대속도 배율 | 조향 응답 | 제동력 | 추가 효과 |
|---|---|---|---|---|---|
| ⬛ 아스팔트 (건조) | 1.00 | 1.00 | 1.00 | 1.00 | 기준값 |
| 🌧️ 젖은 아스팔트 | 0.78 | 0.95 | 0.85 | 0.72 | 수막: 140km/h 이상이면 그립 추가 −15% |
| 🧊 얼음 | 0.32 | 0.85 | 0.35 | 0.28 | 관성 유지, 오버스티어 급발생. 스로틀로 드리프트 제어 |
| 🛢️ 기름 유출 | 0.18 | 0.85 | 0.20 | 0.15 | 진입 순간 조향 완전 무효 0.35초, 스핀 위험 |
| 🏜️ 비포장(자갈) | 0.55 | 0.80 | 0.70 | 0.55 | 요철: 수직 바운스 + 스티어링 저터 + 시야 먼지 |
| 🟫 점프대(램프) | 0.90 | 1.05 | 1.00 | — | 공중 구간: 조향 30%만 유효, 착각 각도 잘못되면 대파손 |
| ⬜ 콘크리트 | 1.05 | 1.02 | 1.05 | 1.05 | 상수 잘 보이는 특별 구간 |

### 5.1 gimmick 배치 규칙
- **기름 유출**: 화면에 **무지개빛 반사**로 반드시 시각 안내. 직전 세그먼트에 경고 표지판.
- **얼음 구간**: 진입 전 300m 청색 LED 도로 매립등 + 김 서린 효과. 구간 진입 시 HUD에 `ICE` 경고 깜빡임.
- **비포장**: 진입 경계에서 `CLUNK` 사운드 + 카메라 셰이크. 바운스 진폭 = 속도 × 0.02
- **점프대**: 착지 지점에 초록 착륙 램프. **공중에서 차회전(360°) 성공 시 콤보 보너스**
- **주의**: gimmick은 최소 150m 간격, 같은 유형 연속 3회 금지 (좌절 방지)

## 7. 차량 물리 / 시뮬레이션

### 7.1 1차 물리 모델 (2.5D에 맞는 단순화)
차량은 2D 질점 + 요(yaw) 모델. 렌더만 유사 3D.

```
상태: pos(x, z), heading θ, 속도 v, 요레이트 r, 스lip각 α

1) v += (driveForce - drag·v² - rollResist) / mass · dt
2) 조향 입력 → targetYawRate = steer · steerCurve(v) · grip
3) r = lerp(r, targetYawRate, 1 - exp(-grip · k · dt))   ← 그립이 낮으면 반응 지연
4) α = atan2 lateralSpeed, v
5) if |α| > limitAngle → DRIFT (타이어 마모 ↑, 스모크 파티클, 콤보 포인트)
6) pos += v · dir(θ + α) · dt
```

### 7.2 물리 상수 기준표 (초기)
| 파라미터 | 기본차량 값 | 설명 |
|---|---|---|
| mass | 1180 kg | 경량화 업글 시 −12% |
| 엔진 출력 | 145 hp | 업그레이드 최대 320 hp |
| 토크 곡선 | 1.0/0.72/0.55 (저/중/고 RPM) | 다운시프트 반영 |
| 최고속 | 232 km/h | 이론치 · 실측(다운포함) 205 |
| 0→100 | 6.4 s | |
| brakedecel | 1.15 g | 노면별 곱 |
| dragCd | 0.34 | |
| downforce | 0.55 | 고속 그립 +22% |
| gripBase | 1.35 (타이어 등급별) | |
| rideDamageThreshold | 0.42 | 초과 시 손상 판정 |

### 7.3 손상(Damage) 4개 시스템
각각 **0~100%** 상태값이고, 0%에 가까울수록 불이익 + 0%에서 **완전 파손(DNF)**.

| 부품 | 100%→0% 영향 | 주요 피해 원인 | 복원 방법 |
|---|---|---|---|
| 🔧 **엔진 HP** | 출력 −최대 55%, 최고속 −30% | 정면/후면 충돌, 전복 | 엔진 수리 키트 / 차고 정비 |
| 🛞 **타이어 마모** | 그립 −최대 45%, 제동 −35%, 편마모 시 자동 편향 | 드리프트, 비포장, 충돌, 시간 | 타이어 교체 쿠폰 |
| ⛽ **연료** | 0% = 리타이어(DNF) | 주행 시간, 부스터 사용 | 고급 휘발유 / 주유소 구간 |
| 🪟 **차체/판금** | 조향 저터, 공력 −, 렌더에 스크래치/연기 | 충돌 마찰 | 차체 판금 쿠폰 |

**가시화:** HUD 4개 게이지 + 차량에서 실시간 피드백(엔진 과열 = 흰 연기, 타이어 파열 = 진동+편향, 연료 부족 = 게이지 빨간 깜빡임 + 경고음)

## 8. 경쟁 AI

### 8.1 동작 원리
- **드리프트 라인 장악(drafting/blocking)**: 세그먼트 중심선을 따라가되, 차선 오프셋 `laneOffset`으로 추월/방해
- **예측:** 전방 8세그먼트를 look-ahead 해 곡률 최대값으로 감속 목표속도 계산
  `vTarget = sqrt(grip · radius · maxLatAccel)`
- **스킬 레벨** (AI마다 배정, 코스별로 상승)

| AI 등급 | 목표속도 배율 | 반응 지연 | 실수율 | 특기 |
|---|---|---|---|---|
| D | 0.86 | 320ms | 14% | 초보, 사고 잦음 |
| C | 0.92 | 220ms | 9% | |
| B | 0.965 | 150ms | 5% | |
| A | 1.00 | 100ms | 2.5% | |
| S | 1.04 | 60ms | 1% | Rubberband 사용 |

### 8.2 Rubberband(느낌 유지) 규칙 — **중요**
플레이어가 1위일 때 AI +6%, 최하위일 때 AI −6% 단, **S등급은 제외**. 역전 드라마를 만들되 조작감을 해치지 않는 선.

### 8.3 상호작용
- 추월 근접(2m 이내) 시 **다운포스트 효과**로 AI가 약간 밀림
- 플레이어 접촉 시 AI는 회피 시도 + 피해 누적
- AI끼리도 충돌 가능 (화려함 + 변수)

## 12. 기술 아키텍처

### 12.1 제약과 원칙 (v0.2 개정)
- **코드 1개 파일**: `index.html` 안에 `<style>`, 마크업, `<script>` 전부
- **외부 라이브러리·CDN·웹폰트 요청 0** (인터넷 연결 없이 동작)
- 실행 형태 2가지 모두 지원:
  | 형태 | 조건 | 결과 |
  |---|---|---|
  | A. 완전 단일 파일 | `index.html`만 있음 | 그래픽 전부 Canvas 절차적 드로잉, 사운드 전부 WebAudio 합성 |
  | B. 코드 + 에셋 폴더 | `index.html` + `assets/game/**` | OpenGameArt 소재를 읽어 배경·장애물·차량·음악이 실제 이미지/오디오로 표시 **(권장)** |
- 형태 판정은 런타임 감지: `Assets.load()`가 목록을 요청 → 404/실패 시 항목별로 절차적 폴백. **에셋이 없어도 게임은 뜬다.**
- `file://` 실행 시 이미지/오디오는 동작하나 **`fetch`(JSON/XML)는 차단**될 수 있음 → atlas 좌표표는 JS 상수(`SPRITES`)로 하드카피하고, `.xml`은 개발 시 생성에만 사용
- 의존성 0, ES2017 범위 문법(모던 브라우저면 충분)

### 12.3 유사 3D 도로 렌더러 (핵심 알고리즘)
```js
// 세그먼트를 카메라 기준 상대좌표로 변환하고 스크린 트apezoid로 그림
project(p, camX, camY, camZ) {
  const scale = CAMERA_DEPTH / (p.z - camZ);          // 깊이
  return {
    x: W/2 + scale * (p.x - camX) * W/2,
    y: H/2 - scale * (p.y - camY) * H/2,
    w: scale * ROAD_WIDTH * W/2,
    scale
  };
}
// 1) camera부터 drawDistance개 세그먼트 순회하며 곡률 누적(x += dx)
// 2) 뒤에서 앞으로 painter's algorithm: 트apezoid(roads) + rumble + 차선
// 3) 세그먼트별 밝기 = 가로등 거리 함수(lampGlow) → 어둠/빛 대비
// 4) props는 scale로 스프라이트 스케일, y-정렬로 가려짐 처리
```
- **가로등 조명**: 세그먼트 밝기 = `max(0, 1 - distToNearestLamp/220)` + 주변광 0.18 → **도로 위에 빛 원통이 이어지는 느낌**
- **네온 bloom**: 별도 오프스크린 캔버스에 발광물만 그리고 `filter: blur` + `globalCompositeOperation='lighter'`로 합성
- **최적화**: 그리드 컬링, 파티클 상한 260, drawDistance 220세그먼트, `devicePixelRatio` 2로 캡

assets/game/**          런타임이 읽는 최종본 (원본은 assets/source/에 보존)
  bg/    파라락 레이어(px_*, 160x144 → nearest 4~8x 업스케일), 사진 배경(jpg)

| **M0 · 뼈대** | 빈 화면 + rAF 루프 + 입력 | 키 입력이 콘솔에 찍히고 FPS 60 유지 |
| **M0.5 · 에셋 레이어** | `Assets` 로더 + `Sprites` 인터페이스 + 폴백 | `assets/` 있을 때와 없을 때 모두 같은 화면이 뜸, 크레딧 데이터 로드 |
| **M1 · 드라이빙** | 곡선 도로 + 플레이어 차 + 가로등 | 직선/커브에서 차가 밀리지 않고 조향됨, fps 60 |
| **M2 · 노면 gimmick** | 얼음/기름/비포장/점프 | 노면별 핸들링 차이가 **눈에 보임**, 점프 착지 동작 |
| **M3 · 레이싱** | 랩/순위/체크포인트/AI 3대 | 1위 입력 시 순위 1위, 타임 기록 저장 |
| **M4 · 손상/경제** | 엔진·타이어·연료·차체 + 상점 + 저장 | 파손 후 정비하면 성능 회복, 포인트 증감 정확 |
| **M5 · 연출/화려함** | 네온, 파티클, 카메라, 사운드, HUD 마감, **크레딧 화면** | 첫 판 플레이하고 "GTA 같다"고 느껴짐, 크레딧에 CC-BY 표기 노출 |
| **M6 · 콘텐츠/밸런스** | 코스 5개, 모드, 튜닝 | 5개 코스 클리어 + 경제 곡선 검증 |
| **M7 · 폴리쉬(선택)** | 리플레이, 패드, 접근성, 모바일 터치 | |

**1차 릴리스 범위 = M0~M6 (M0.5 포함).** 각 단계 끝에 브라우저로 실시간 확인(플레이 테스트)을 진행합니다.

## 14. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| 유사 3D 곡선 렌더링이 어색함 | 높음 | M1에서 커브+언듈레이션 검증 후 확대. 곡률 누적 공식 기준값 상수화 |
| 단일 HTML 파일이 5000줄 이상 | 중간 | 파일은 하나이되 namespace로 섹션 구분, 주석 배너로 탐색성 확보 |
| 밸런스 붕괴(성장 속도/난이도) | 중간 | 모든 수치를 `CONFIG`로 모아 콘솔에서 실시간 튜닝 |
| 손상 시스템이 좌절 유발 | 중간 | 코스1은 손상 50% 완화, 방치 선택 가능, DNF 전 자동 경고 3회 |
| 연료로 인한 정체 | 중간 | 기본 레이스는 연료 110%로 시작, 코스1 연료 소모 30% 감소 |
| 에셋 로드 실패(경로·`file://` 정책) | 중간 | 항목별 폴백(§12.6). atlas 좌표는 JS 상수로 포함해 fetch 의존 제거 |
| 외주 아트가 게임 톤과 안 맞음(픽셀 160px vs 2.5D) | 중간 | 저해상도 아트는 **배경·원경 전용**, 근접·차량은 절차적 드로잉. 업스케일 시 nearest + 톤 보정 |
| 라이선스 표기 누락 | 높음 | `assets/credit_report.json` 기준 감사 → `CREDITS.md` + 게임 내 크레딧 화면(M5) |
| 음악 용량 초과(현 9.3MB) | 중간 | 커트 길이 축소(≤3MB) + 설정에서 음악 OFF 기본값 허용 |
| 모바일 미지원 | 낮음 | 1차는 데스크톱 한정 + "터치 지원 예정" 안내 |

## 15. 확정된 결정 사항 / 남은 질문

### ✅ 확정
1. 그래픽: Canvas 2D 유사 3D (OutRun/GTA1 계열)
2. 배포: `index.html` 단일 코드 파일, 라이브러리 의존성 0, 오프라인 실행 (v0.2: + 선택적 `assets/` 폴더)
3. 시점: **후방 3/4 뷰**(camera behind) — 속도감과 차 확인 둘 다
4. 손상 4계통(엔진/타이어/연료/차체), 상점·업그레이드·저장 포함
5. AI 경쟁 + 교통차 + 점프/얼음/기름/비포장 전부 1차 포함
6. 소재: OpenGameArt 개방 라이선스(CC0 / CC-BY / OGA-BY)를 사용하고 **크레딧 표기**, 없는 소재는 절차적 생성
7. 잔여 질문 5개(§15 아래)는 답변 미회신 → **제시된 기본값으로 진행**

### ❓ 확인하고 싶은 것 (답 없으면 기본값으로 진행)
1. **시점**: 후방 뷰 기본. 1인칭(캐빈/보닛 뷰) 전환 버튼을 넣을까요? → 기본: 넣음(`C`키)
2. **경찰/순찰차 요소**: GTA 감성을 위해 순찰차 추격을 넣을까요? (장애물로 취급) → 기본: M7 선택 항목
3. **연료 긴장감**: 강하게(주유 필수) vs 약하게(연료 압박 적음) → 기본: **약하게**
4. **한국어 UI**: 기본 한국어, `E`키로 한/영 전환 → 기본: 한국어 단일
5. **차량 커스터마이징**(색/네온/림): 재미 요소지만 범위 ↑ → 기본: **색상+네온만** (M6)
