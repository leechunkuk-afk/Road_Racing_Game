`car_hero_090.jpg`(측면) · `car_sheet.png`(yaw 16프레임 접시. 칸 순서는 왼쪽→오른쪽, 위→아래로 0/5/10/15/20/25/30/35/40/45/60/75/90/120/150/180도)

## 2. 차량 치수 (실측, 미터)

`car.json` 기준: **전장 4.300 / 전폭 1.976 / 전고 1.224**, 휠베이스 2.45, 트레드 1.69, 타이어 반지름 0.345,
접지점 z = 0(정렬 완료). 목표 대비 오차 0.000 / +0.026 / +0.004 (전폭 +26mm 는 휠 면이 10mm 돌출된 때문).

- 형상: 22개 superellipse 링을 X 축으로 로프트한 본체 + 9개 링의 캐빈(지붕=페인트, 옆면=유리),
  휠아치는 반원통 4개를 EXACT 불리언으로 잘라 만들었다.
- 소일부: 사이드스커트·디퓨저(핀 5)·범퍼 인서트·그릴·스플리터·리어 LED 스트립·리어 클러스터·DRL·
  덕테일 윙·번호판·미러, 타이어 4 + 휠면 4 + 허브 4 + 브레이크 캘리퍼 4 + 배기구 2.
- 총 8개 오브젝트 / 1848 정점. 게임 스프라이트 크기(약 200px)에서는 스포크·핸들 같은 세부 묘사가 보이지 않아 의도적으로 생략했다.
- 재질: paint(메탈릭 0.86 + 코트 0.55 → 가로등 반사), trim(무광 검정), glass(짙은 틴트),
  lampR(발광 6.0), lampW(발광 2.2), plate, tire, rim, caliper.

## 3. 스프라이트 프레임 (게임 연결용 규격)

`assets/car/car_frames.json` 가 그대로 담고 있는 값:

| 항목 | 값 |
|---|---|
| 프레임 크기 | 384×384 px, PNG RGBA(straight alpha · premultiply 없음) |
| 렌더 스케일 | `ortho_scale 4.8m` → **px_per_m = 80.0** (게임의 접지선 축척 80px/m 과 동일) |
| 프레임 수 | 16개 = yaw 0~45(5° 각) + 60/75/90/120/150/180 |
| 좌우 반전 | `mirror_negative_yaw: true` — 음수 yaw 는 좌우 반전으로 재사용(조명·차체가 XZ 평면 대해 대칭) |
| 앵커 | `anchor.ground_y = 241`(차 중심 타이어 접지선 행), `anchor.ground_x = 192` |
| yaw 규약 | 0 = 뒤에서 본 모습, + = 차가 오른쪽으로 튼 각도(좌측 flank 노출) |
| 파일 크기 합계 | 1.24 MB (프레임당 약 77 KB) |

- 앵커는 bbox 아래변이 아니다. bbox 아래변은 front 스플리터가 피치 10° 때문에 접지선보다 22px 아래로 내려와서
  측정값 262~264 로 찍힌다. 게임은 반드시 `ground_y` 를 접지선에 맞춘다.
- 화면에서의 크기: 전폭 1.976m × 80px/m = **158px**(yaw 0), 측면 4.30m × 80 = 344px(yaw 90).

## 4. 수치 검증 (이미지를 못 보는 환경에서의 확인)

- 정후방 프레임 ink = 160×119 px → 1.98m×… 로 전폭 실측과 일치. 측면 ink 346px → 전장 4.29m 로 일치.
- 접지선 행(ground_y) 는 yaw 와 무관하게 240.8 로 고정(직교 카메라라 거리·yaw 영향 없음).
- 정합성: `-20°`/`-90°` 를 실제로 렌더해 `+20°`/`+90°` 의 좌우 반전과 비교 → rgb 평균절대오차 0.0026 / 0.0041,
  alpha 0.0002 / 0.0030 (0~1 스케일). 반전 재사용은 안전하다.
- 알파 형식: straight alpha 확인(premul 누수 픽셀 0 이 아니라 "색 > alpha" 가 관측됨 → straight).
- 발광 확인: 정후방 프레임에 빨강 계열(테일) 2368 px, 측면 프레임에 흰 계열(휠면) 8930 px.

## 5. 다음(게임 연결) — 승인 후 진행

1. 프레임 파일을 `assets/game/car/` 로 옮기고 `CONFIG.assets.list` 에 16종 등록(에셋이 없으면 기존 `Sprites.carRear` 절차적 폴백 유지).
2. `Sprites.carSprite(ctx, yawDeg, cx, groundY, scale)` 구현: `|yaw|` 로 가장 가까운 프레임 선택,
   음수 yaw 는 `ctx.scale(-1,1)` 로 반전. 그리기 축척 = `Render.pxPerMeterAt(cy) / px_per_m`.
3. 손상/브등/니트로 효과는 렌더를 다시 만들지 않고 캔버스 오버레이(전파·연기·불꽃) 로 얹는다.
4. `CREDITS.md` 에 "차량은 자체 Blender 렌더(제3자 자산 미사용)" 표기.
