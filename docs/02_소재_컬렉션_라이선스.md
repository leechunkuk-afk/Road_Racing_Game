# 02. 소재 컬렉션 & 라이선스 (Assets & Licensing)

작성: 2026-11-10 · 기준 문서: [`docs/01_기본작업_기획서.md`](01_기본작업_기획서.md) (v0.2)

이 문서는 **어디서 얻은 소재를 게임 어디에 쓰는지**, 그리고 **라이선스상 무엇을 지켜야 하는지**를 기록한다.
크레딧 문구의 원문은 [`CREDITS.md`](../CREDITS.md).

---

## 0. 수집 파이프라인 (재실행 가능)

| 단계 | 스크립트 (`tools/asset_pipeline/`) | 산출물 |
|---|---|---|
| ① 후보 페이지 선별 | `oga_candidates.json` (40 URL) | — |
| ② 페이지 크롤링(제목/파일/라이선스) | `01_harvest_pages.ps1` | `out_harvest.json` |
| ③ 다운로드 | `assets_manifest.json` + `02_download.ps1` | `assets/source/**` (36개, 약 105MB) |
| ④ zip 해제·내용물 확인 | `03_extract.ps1`, `04_probe.ps1` | 추출 폴더 |
| ⑤ 런타임용으로 추려 복사·리사이즈 | `05_organize_game_assets.ps1` | `assets/game/**` |
| ⑥ 음악 커트/다운샘플 | `07_music_prep.js` (Node, 무의존) | `assets/game/music/**` |
| ⑦ **정확한 저자·라이선스 재수집** | `06_credits.ps1` | `assets/credit_report.json` |
| ⑧ 문서 텍스트 품질 검사 | `08_scan_docs_text.ps1` | 콘솔 리포트 |

실행 예시 (저장소 루트 기준, 기본값이 경로로 내장되어 있어 인자 없이 동작):
```
powershell -NoProfile -ExecutionPolicy Bypass -File tools\asset_pipeline\06_credits.ps1
node tools\asset_pipeline\07_music_prep.js .
```

주의(환경 사실):
- OpenGameArt는 `webfetch`·내장 브라우저 경로가 **403 Forbidden(nginx)** 으로 차단 → 로컬 PowerShell `Invoke-WebRequest`(Chrome UA)로 수집.
- 저자 필드는 `field-name-author-submitter` 블록 안의 `username` 링크만 유효. (첫 번째 `/users/` 링크는 댓글 작성자라 틀림)
- `ffmpeg`/`magick` 미설치 → 이미지는 `System.Drawing`, 오디오는 Node 수작업(태그 파싱/프레임 커트/PCM 다운샘플).

## 1. 폴더 규칙

```
assets/
  credit_report.json     페이지별 저자·라이선스 원본 데이터(⑦ 결과)
  source_manifest.json   다운로드 36건의 url/dir/name/page/license 기록
  source/                원본 유지물 (zip + 추출 폴더). 런타임에서 읽지 않음. 약 105MB
  game/                  런타임이 사용하는 경량본. 이것이 최종 에셋.
    bg/    cars/    props/    sfx/    music/    atlas/
```

원칙: `source/`는 "원작자 확인·재가공"용 보존, **게임은 `game/`만 읽는다**.

## 3. 용량 예산 (웹 배포 관점)

| 항목 | 현재 | 목표 | 조치 |
|---|---|---|---|
| 이미지(atlas+bg+cars+props) | 약 560KB | ≤ 900KB | 현재로 충족 |
| SFX | 약 700KB | ≤ 800KB | 충족 |
| 음악 | **9,308KB** | **≤ 3,000KB** | 커트 길이 단축(72s→36s) 또는 저비트 재인코딩(도구 필요) |
| `index.html`(코드) | — | ≤ 300KB | 단일 파일 유지 |

음악 축소 후보: `night_drive_cut.mp3` 36s(1.4MB), `race_cut.mp3` 28s(0.9MB), `menu_cut.mp3` 28s(0.9MB) → 루프 재생으로 충분히 느껴짐.
`chip_*.wav`는 저사양 폴백이므로 배포 zip에서 제외 가능(개발용 유지).

| **OGA-BY 3.0** | Carlos Alface, overcrafted, CraftPix, TRBRY | 위와 동일(OGA-BY는 OpenGameArt 링크 포함) |
| GPL 2.0/3.0 (dual에 포함된 것) | qubodup(boost), fridaruiz(bg) | CC-BY 쪽 선택해 사용 → GPL 전제조건 미적용 |

- 개작: 리사이즈·커트·다운샘플·업스케일 → CC-BY/OGA-BY는 **변경 표시** 권장 → CREDITS.md에 "리사이즈/트리밍됨" 각주 유지.
- 금지: 라이선스 위반 상태로 재배포하지 않기(배포 시 원본 라이선스 텍스트 동봉).
